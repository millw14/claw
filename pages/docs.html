Introduction

ClawCrypt is an AI-powered wallet intelligence platform for Solana. Instead of complex dashboards and technical queries, you simply ask questions in plain English.

Example "Track this wallet and tell me when it buys"

Quick Start

1

Enter the Chat

Click "Enter Chat" on the home page to open the AI interface.

2

Ask a Question

Type any wallet-related question in plain English.

3

Get Insights

Receive AI-analyzed results with actionable intelligence.

How It Works

ClawCrypt uses a combination of:

  • Natural Language Processing - Understands your questions and converts them to on-chain queries
  • Solana RPC - Fetches real-time blockchain data
  • Helius API - Enhanced transaction parsing and wallet analysis
  • AI Classification - Labels wallet behavior patterns

Natural Language Search

No commands to memorize. Just type what you want:

"Track this wallet"
"Find wallets holding over 2M $TOKEN"
"Show wallets active during this launch"
"Who bought early and never sold?"

Wallet Discovery

Find wallets even without the full address:

  • Partial Address - First or last characters
  • SNS/ENS Names - Domain-based lookup
  • Token-based - "Top holders of $XYZ"
  • Time-based - "Wallets active around Jan 2024"

Wallet Profiles

Auto-generated profiles include:

  • Current SOL & token balances
  • Token holdings breakdown
  • First seen / last active time
  • Activity frequency
  • Top tokens interacted with
  • Simple PnL estimate

Behavior Analysis

AI classifies wallets into behavior types:

Whale Sniper Farmer Diamond Hands Serial Dumper Team-linked

Alerts & Monitoring

Subscribe to real-time alerts:

  • Wallet buys/sells
  • Large transfers
  • Token accumulation
  • Dormant wallet activity

Alerts delivered via Telegram, Discord, or in-app notifications.

API Overview

For developers who want programmatic access:

Base URL https://api.clawcrypt.io/v1

Endpoints

GET /wallet/{address}

Get wallet profile and analysis

POST /query

Natural language query endpoint

POST /alerts/subscribe

Subscribe to wallet alerts
